# Himisha Talasila — portfolio

A single-page portfolio for Himisha Talasila Chowdary, brand & marketing strategist in Hyderabad.
The site reads as a conversation: visitors "ask" questions and her answers carry the content,
ending in a composer that opens WhatsApp with the visitor's note.

Static HTML, no build step. Deployed on Vercel.

Site by [Vamshi Creates](https://vamshicreates.tech).
